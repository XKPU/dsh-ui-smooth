# Changelog

## [v0.1.1] - 2026-11-27

### Fixed

- **「后台不节流」在所有宿主生效**：DSH 的壳没有给宿主任何窗口控制通道（与壳的 IPC 仅 shutdown / quit-inspection / update-tasks），因此移除了宿主半的 `setBackgroundThrottling` 路径与 `navigator.userAgent` 判定，统一由页面侧的一条 40 Hz、增益 0.0001 的静音音频流保活：Chromium 不会把正在播放音频的渲染进程放进后台节流集合，浏览器标签页与桌面壳同理。开关打开即关闭音频流。
- **静音音频流等待用户手势**：在页面尚未收到交互、AudioContext 处于 `suspended` 时，挂在首次 `pointerdown` / `keydown` / `wheel` / `touchstart` 与切回前台的 `visibilitychange` 上重试 `resume()`，真正开始播放后才算保活生效；关闭时一并移除这些监听。
- **切回前台不再整段重排**：窗口恢复可见或 resize 后，先让出 900 ms 给应用补帧，再由视口附近的观察器装回那些轮次，不再一次性恢复所有已摘除的行；根据盒子预先批量测量后再统一改动 DOM，避免逐行触发布局。后台定时器在页面隐藏时也跳过配置拉取。
- **修复轮次被摘除或隐藏渲染时的页面漂移**：`skip` 档原先给所有轮次套固定的 `contain-intrinsic-size: auto 320px`，实测在同一份 246 轮会话上会把整段高度从 54,341px 撑到 77,409px，下方内容整体下移，视口看起来像自己滚动了。现在两档都改用轮次**实际测得的 border-box 高度**：`skip` 通过 `contain-intrinsic-size: auto var(--ui-smooth-height)` 加上同值 `min-height` 保留高度，`parked` 用测量值占位，并统一 `box-sizing: border-box`；无高度可测的轮次保持正常渲染，不再塞一个它从来没有过的占位高度。同一会话下开启该档后总高仍是 54,341px，顶部轮次与滚动中的位置都不漂移。
- **切回前台回到最新消息（新开关，默认开启）**：由「前台与后台」组的「切回前台滚动到最新」控制。开启时，若窗口隐藏前读者停在会话底部，回到前台后用两帧的时间滚回最新一条，避免积压内容堆在视口上方；若当时正在读旧历史，则保持原滚动位置不动。关闭后不改滚动位置。它与「后台节流」相互独立：一个决定隐藏窗口是否继续渲染，另一个只在回前台那一刻生效。
- 移除 `status()` 里的 `electron` 字段与配置响应中的 `electron` 字段；`throttle()` 现在只返回页面音频流的状态（`active` / `state`）。

### Changed

- 设置页「流畅性」由一长列改为三组：**渲染**（启用动画优化）、**前台与后台**（后台节流、切回前台滚动到最新）、**旧轮次回收**（流式输出期间回收、旧轮次跳过渲染、旧轮次从文档流摘除、激进策略：旧轮次从内存卸载）。
- 设置页「后台节流」开关在所有环境可用，不再置灰；提示文案不再区分桌面端与浏览器端。
