# Changelog

## [v0.1.0] - 2026-11-27

首个正式版本，包含此前全部功能。仅支持最新版本：不为旧版本插件或旧版配置提供迁移与兼容分支。

### Added

- **启用动画优化（默认开启）**：空闲态无限循环的布局/绘制动画被改写为合成友好形式：
  - 伪元素扫光（`left: -Npx → 100%`）改写为 `transform` 扫光，轨迹逐点等价。
  - 其余布局/绘制动画按 `steps()` 降采样（布局 ~8 次/秒，绘制 ~4 次/秒）。
  - 只处理 `infinite` 动画；有限动画、已合成属性与 `prefers-reduced-motion: reduce` 不动。
- **旧轮次跳过渲染（默认开启，早于 3 轮且超过 5 分钟）与旧轮次从文档流摘除（默认开启，早于 5 轮且超过 16 分钟）**：够旧且久未进视口判定的：
  - `skip`：整棵子树 `content-visibility: hidden`，不参与布局、样式与绘制。
  - `unmount`：整棵从文档里摘下（子节点移进游离的 `DocumentFragment`，行按原高度占位），接近视口时按原顺序装回。
  - 「流式输出期间回收」默认开启，流式输出时仍按阈值处理；关掉该开关后检测到 `[data-streaming]` 就整轮暂停回收，等这一轮结束再按阈值处理。
  - 阈值改动、切回前台、窗口 resize 或配置重新拉取后，会先把已卸载的轮次全部装回再重算。
  - 修复观察器只在创建时登记行的问题：历史分块后新出现的轮次现在也会被监视，卸载后可自动装回。
- **后台节流（默认开启）**：关掉开关后两层生效——宿主半若确实运行在 Electron 主进程里，优先对每个 `webContents` 调用 `setBackgroundThrottling(false)`；DSH 的壳没有给宿主窗口控制通道（与壳的 IPC 仅 shutdown / quit-inspection / update-tasks），页面半同时开一条 40 Hz、增益 0.0001 的静音音频流，让 Chromium 不把渲染进程放进后台节流集合；开关打开即关闭音频流。是否在桌面壳中由页面 `navigator.userAgent` 的 `Electron/` 判定，设置项不再置灰。
- **激进策略：旧轮次从内存卸载（默认关闭，默认「早于 8 轮」且「重新加载后 20 分钟内没再查看过」）**。前两档只是让浏览器少干活，节点仍归 React；这一档走会话控制器自己的历史窗口，两个条件必须同时满足才会真卸载：被查看过的轮次重新计时，刚从磁盘读回的轮次也要等自己的冷却走完。满足条件的旧轮次被截掉后由 React 真正卸载，fiber 与它持有的 DOM 一起被回收：
  - 截断后 `hasMore` 保持为真，「加载更早」会把这些历史从磁盘原样读回来；
  - 同步移动分页流的 `firstCursor`，否则它会认为请求的页与已持有的窗口重叠，静默丢弃整页；
  - 只在可丢弃轮次不少于 4 轮时才出手，避免和「加载更早」的 500 条一页形成反复拉取。
- **设置面板「流畅性」**：通过 `settings.section` 插槽注册，六项开关对应动画优化、后台节流、流式输出期间回收、旧轮次跳过渲染、文档流摘除与激进卸载；各档轮数与时长阈值可在面板内调整，顶部显示当前版本 `v0.1.0`。
- **配置读写**：宿主半提供 `/dsh-ui-smooth/config` 的 GET/HEAD/POST，配置保存在 `$DSH_HOME/dsh-ui-smooth.json`；页面半缓存同一份配置并把变更广播给设置面板与回收器。配置只接受当前定义的字段：未知键一律忽略，缺失字段回落默认值。
- **诊断句柄**：`window.__dshUiSmooth` 提供 `status()`、`config()`、`history()`、`throttle()`（宿主回报、UA 判定与静音音频流状态）以及 `rescan()`、`recycle()`、`refreshConfig()`、`restore()`；把 `dsh-ui-smooth:debug` 写入 `localStorage` 后输出控制台诊断。
